# MEIKO Wellness

Service-led website for MEIKO Wellness Puchong, with the RM68 four-service experience and WhatsApp enquiries at +60 12-268 9133.

## Website
- Canonical domain: https://meikowellness.my/
- Static HTML, CSS and JavaScript. No build or backend is required.
- Publish the repository root with GitHub Pages; retain `CNAME` and `.nojekyll`.
- Local preview: `python -m http.server 8000`, then open http://localhost:8000.

## Content and design
Brand red, supplied store photography, ImageGen campaign title, supplied flower favicon and desktop cursor, responsive layout, Chinese/English switch, four service tabs, and reduced-motion support. WhatsApp links prepare an enquiry; the website does not send messages or confirm bookings automatically.

## Search metadata
Canonical URL, description, Open Graph/Twitter cards, visible business summary, Organization / HealthAndBeautyBusiness / WebSite / WebPage / Service / Offer / FAQ JSON-LD, `robots.txt`, `sitemap.xml` and an optional `llms.txt` summary. Structured data matches supplied store and offer facts. Unknown opening hours, coordinates, reviews and medical outcomes are not invented.

Google Search Console ownership verification and sitemap submission need the domain owner's account; these are not configured in the repository. No ranking, FAQ rich result or AI citation is guaranteed. The language switch is a client-side convenience, not separate indexed language URLs.
